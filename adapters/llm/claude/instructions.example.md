# Exemplo: instruções do projeto (ambiente de agente da Anthropic)

Salve como o arquivo de memória de projeto da ferramenta usada, na raiz do workspace do agente.

```
Siga integralmente as instruções em AGENT.md, na raiz deste repositório.
Leia AGENT.md antes de qualquer tarefa e as políticas em policies/ quando ele indicar.
Não coloque conhecimento de nenhum software nestas instruções: ele vive em software-packs/.
```

Este arquivo é só um ponteiro. A única fonte de instruções é `AGENT.md`.
